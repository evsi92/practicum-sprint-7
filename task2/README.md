## Краткое описание процесса формирования текстов
 Источник - https://harrypotter.fandom.com/wiki/Main_Page  
 Тексты скопированы на английском языке, чтобы избежать трансформации, преобразования окончаний. И ожидается, что бот будет лучше работать с английским языком.  
 - Вручную выбрано 30 статей и перенесены в txt файлы в папку task2/original.
 - Вручную / с помощью простых скриптов удалены ссылки в квадратных скобках.
 - С помощью ИИ выбраны из текстов имена собственные, места, артефакты, предметы, заклинания. 
 - Затем частично вручную, большей частью с помощью ИИ подготовлен файл task2/replaced/dictionary.txt.
 - Подготовлен скрипт task2/replaced/replace_words.py, который заменил имена и тд в оригинальных файлах.
 - Файлы вручную переименованы.
